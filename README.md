# Дог-бот

![Telegram](https://img.shields.io/badge/python_telegram_bot-13.7-green)
![Postgress](https://img.shields.io/badge/Postgress-12-green)

Переделал бота на обучении с котиков на догов. Есть одна кнопка, которая отправляет вам нюдога(`НюДог`). Если вам нравятся собакены, то понравится и этот бот. Для опыта так же прикручена БД на `Postgres` - записывается `id` пользователя, его имя и дата его взаимодействия с ботом. Позже есть идея прикрутить сюда аналитику на `DataLens`. Так можно будет видеть в какое время, в какой день недели, как часто пользователи тыкают нюдогов.

Есть возможность оповещать несколько пользователей об активности нюдога, то есть когда бот работает. Пока это сделано в окружении, но можно и добавить поле в БД, и тогда опрашивать юзера, а хотел бы он, чтобы бот его оповещал, когда снова станет активным.

Запускать файл `app.py`, который в двух потоках запустит сразу двух ботов.

Структура файла `.env`:
```
TG_TOKEN=<токен для телеграм бота>
DB_NAME=<имя БД>
DB_USER=<имя пользователя БД>
DB_PASSWORD=<пароль пользователя БД>
DB_HOST=<хост ДБ>
USER1=<пользователь для оповещения>
USER2=<пользователь для оповещения>
VK_TOKEN=<токен вк сообщества>
VK_GROUP=<идентификатор группы вк>
TG_TABLE=<имя таблицы с пользователями для тг бота>
VK_TABLE=<имя таблицы с пользователями для вк бота>
```
На текущий момент можно просмотреть сколько пользователей запрашивали догов так:
```
SELECT 
    user_telegram_id AS user_id, 
    user_name, 
    COUNT(user_telegram_id) AS user_count,
    'telegram' AS source  -- Указываем источник данных
FROM telegram
GROUP BY user_telegram_id, user_name

UNION ALL

SELECT 
    user_vk_id AS user_id, 
    user_name, 
    COUNT(user_vk_id) AS user_count,
    'vk_dog' AS source  -- Указываем источник данных
FROM vk_dog
GROUP BY user_vk_id, user_name;
```
